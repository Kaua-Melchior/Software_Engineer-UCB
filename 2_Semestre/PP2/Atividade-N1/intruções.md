Avaliação N1 — Sistema de Compra de Carros em Linguagem C

Componente curricular: Programação / Algoritmos

Duração: 2 a 3 semanas

Metodologia: Aprendizagem Baseada em Projetos — Project-Based Learning

Conteúdos avaliados: entrada de dados, estruturas condicionais (if/else e switch) e estruturas de repetição (while ou for)

Pontuação: 0 a 4,5

Atenção: o programa precisa compilar e rodar. Testem o código antes de entregar.

1. Objetivo
Desenvolver, em linguagem C, um sistema que ajude a decidir se um cliente pode comprar um carro. O programa deve evoluir ao longo do bimestre, ganhando novas funcionalidades conforme cada conteúdo for visto em aula.

2. Etapas sugeridas
As etapas abaixo são uma sugestão de evolução do projeto, acompanhando a ordem dos conteúdos em sala. Cada um pode adaptar os dados e as regras do sistema, desde que mantenha o tema.

Etapa 1 — Cadastro (entrada de dados)

ler os dados básicos do cliente e do carro (por exemplo: nome, renda, preço do carro);
exibir os dados lidos na tela.
Etapa 2 — Decisão simples (if/else)

usar if/else para tomar uma decisão sobre a compra, com base em uma regra definida (por exemplo: renda suficiente ou não).
Etapa 3 — Classificação (switch)

usar switch para classificar o cliente em diferentes situações (por exemplo: aprovado, em análise, reprovado), a partir da regra definida.
Etapa 4 — Repetição (while ou for) e relatório final

usar while ou for para processar mais de um cliente;
imprimir um relatório final completo com o resultado de todos os clientes processados.
